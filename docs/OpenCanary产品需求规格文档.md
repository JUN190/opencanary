# OpenCanary产品需求规格文档

## 1. 产品概述
OpenCanary是一款开源蜜罐解决方案，旨在通过模拟多种常见服务来检测和记录未授权访问尝试。该系统能够部署在各种网络环境中，帮助安全团队识别潜在的攻击行为并收集威胁情报。

## 2. 整体架构
OpenCanary采用模块化架构设计，主要包含以下核心组件：
- **配置系统**：负责加载和管理系统配置
- **日志系统**：处理所有事件日志的收集、格式化和分发
- **服务模块**：模拟各种网络服务的蜜罐实现
- **告警机制**：将重要事件通过多种渠道通知管理员
- **核心框架**：提供服务注册、生命周期管理等基础功能

## 3. 核心组件说明
### 3.1 配置系统
配置系统通过`config.py`实现，支持以下功能：
- 加载JSON格式的配置文件
- 环境变量扩展和敏感信息处理
- 模块启用状态管理
- 配置值的获取与验证
- 配置文件的保存功能

### 3.2 日志系统
日志系统在`logger.py`中实现，主要特性包括：
- `LoggerBase`基类定义日志接口
- `PyLogger`具体实现支持多种日志类型
- 日志数据清洗和标准化
- 支持通过Socket发送JSON格式日志
- 与告警系统集成

### 3.3 核心框架
核心框架在`__init__.py`中定义了两个关键基类：
- `CanaryProtocol`：扩展Twisted协议类，提供传输层信息记录
- `CanaryService`：提供日志记录、蜜凭证处理和资源访问等通用功能

## 4. 子模块流程图
### 4.1 SSH服务流程图
```
客户端连接 → 协议握手 → 认证尝试(用户名/密码) → 记录日志 → 拒绝访问
```

### 4.2 HTTP服务流程图
```
客户端请求 → 解析请求 → 记录访问信息 → 提供虚假响应 → 记录交互日志
```

### 4.3 FTP服务流程图
```
连接请求 → 返回banner → 认证尝试记录 → 拒绝访问 → 记录详细日志
```

### 4.4 MySQL服务流程图
```
连接请求 → 协议握手 → 解析认证信息 → 记录用户名/密码 → 返回拒绝信息
```

## 5. 内部接口说明
### 5.1 CanaryService接口
- `log(logdata)`: 记录事件日志
- `getHoneyCreds()`: 获取蜜罐凭证列表
- `getResource(filename)`: 访问资源文件
- `startService()`: 启动服务
- `stopService()`: 停止服务

### 5.2 日志接口
- `log(type, src_ip, src_port, dest_port, data)`: 通用日志记录方法
- `alert(alert_type, message)`: 触发告警的接口

## 6. 外部接口说明
### 6.1 服务端口
OpenCanary支持以下服务端口配置：
- SSH: 默认22端口
- HTTP: 默认80端口
- FTP: 默认21端口
- MySQL: 默认3306端口
- Telnet: 默认23端口
- 其他可选服务: RDP(3389), SNMP(161), SMB(445)等

### 6.2 告警接口
- SMTP: 邮件告警配置
- Webhook: HTTP回调接口
- Slack/Teams: 团队协作工具集成
- Syslog: 系统日志集成
- HPFeeds: 威胁情报共享协议

## 7. 配置说明
系统配置通过JSON格式文件管理，主要配置项包括：
- 服务启用状态
- 端口号设置
- Banner信息定制
- 日志处理器配置
- 告警接收者设置
- 蜜罐凭证配置
